# Objectives

| ID | Intended outcome |
|---|---|
| OBJ-01 | Help a single user turn notes into coherent writing. |
| OBJ-02 | Translate Greek and English while preserving meaning, intent, terminology and voice. |
| OBJ-03 | Keep inference local through Ollama with no automatic remote fallback. |
| OBJ-04 | Preserve originals independently and require human review and approval. |
| OBJ-05 | Bound filesystem access to user-authorized actions. |
| OBJ-06 | Establish an evidence-based, proportionate foundation before R1. |

Objectives describe intended outcomes; they are not evidence of delivered behavior.
