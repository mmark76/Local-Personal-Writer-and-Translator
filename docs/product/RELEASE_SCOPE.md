# Release scope

## R0 — initialization, in preparation

Project-specific governance, documentation, requirements, architecture, risks and verification planning. No application code, installer, model download, system configuration or functional tests.

## R1 — prospective MVP, NOT APPROVED

Writer, Greek ↔ English translation, local model selection, review, approval and export are candidates, subject to a separately approved scope and resolved technical decisions. Nothing in R0 authorizes their implementation.
