# Operations and recovery — planned

Provider unavailability must be visible and must not trigger remote fallback; preserve the user's original and allow retry after the cause is resolved. If persistence is approved, define storage ownership, backup, restore, integrity and failure procedures and test restoration before relying on them. Packaging, updates, rollback and actual model availability depend on DEC-006 and DEC-007. No operational procedure or recovery capability has been implemented or verified. Owner: project owner.
