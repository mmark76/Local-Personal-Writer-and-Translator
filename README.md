# Local Personal Writer and Translator

R0 documentation preparation; no application has been implemented. This is a personal, single-user Windows project. Planned Writer functionality turns notes and bullet points into coherent writing. Planned Greek ↔ English translation preserves meaning, intention, terminology and personal voice, subject to human review and approval.

The intended profile is LOCAL_ONLY, with Ollama as the initial local inference provider. Originals remain separate from generated output; no automatic cloud inference or remote fallback is authorized. File access requires user authorization. Actual security and privacy properties require implementation and verification.

R0 covers project governance, requirements, architecture, risk and verification planning only. R1 is a prospective MVP, not approved for implementation. Technology, UI form, persistence, exports, design system, hardware/models and distribution remain open.
